# Caroline Santos Odontologia — Website Profissional

Website profissional institucional desenvolvido para a clínica **Caroline Santos Odontologia**, localizada em Atibaia/SP. O projeto foca em alta performance, design responsivo moderno, acessibilidade e conversão de pacientes via canais diretos de atendimento.

## Principais Recursos

* **Design Responsivo & Mobile First:** Experiência fluida otimizada para smartphones, tablets e desktops.
* **Páginas Institucionais e Tratamentos:** Seções dedicadas para implantes dentários, próteses protocolo e enxertos ósseos.
* **Otimização para Mecanismos de Busca (SEO):** Estrutura semântica HTML5, sitemap XML, meta tags e configuração de indexação local.
* **Integração de Contato:** Botões e chamadas diretas para agendamento de consultas via WhatsApp e telefone.

## Tecnologias Utilizadas

* HTML5 Semântico
* CSS3 Moderno (Layout flexível e responsivo)
* JavaScript Puro (Vanilla JS)
* Apache (`.htaccess`) para roteamento e cache
